The folder "bm_calculator" contains:

1. "bm_calculator.ipynb" program file: a notebook to calculate body mass using femur length and / or femur circumference.
2. The source scripts ("script_random_forest" and "script_neural_networks") in Python (.py) format, which act as libraries to run the program.
3. Training datasets in .xlsx format. The default training dataset is 'Table_S8_full_train_data', for which error boundaries were calculated for.
4. For Random forests, the first result is the body mass (in grams) after training RF with default hyperparameters. The second result is the result after training RF with optimized hyperparameters.

The above three itmes must be in the same folder to run the program.
